## 🚀 Capacidades y Secciones del Sitio

1. **Hero de Alta Tecnología:**
   - Composición interactiva con **Canvas HTML5 nativo** que simula nodos de red interconectados, paquetes de datos pulsantes y telemetría operativa a 60 FPS.
   - Enlaces directos a soluciones y atención inmediata por WhatsApp.
2. **Selector de Necesidades Empresariales ("¿Qué necesita tu empresa?"):**
   - Navegación rápida por categorías estratégicas: *Seguridad, Conectividad, Infraestructura, Tecnología, Entornos Híbridos y Transformación*.
3. **Portafolio B2B (6 Bloques):**
   - Infraestructura TI
   - Ciberseguridad & Resiliencia
   - Conectividad Empresarial
   - Gestión de TI
   - Productividad y Colaboración
   - Transformación Digital
4. **Profundización Técnica:**
   - Despliegue de Infraestructura y Redes con telemetría de continuidad.
   - Modelo de **Defensa en Profundidad** (4 capas de ciberresiliencia).
   - Matriz de conectividad y colaboración híbrida.
   - Consultoría estratégica en 4 fases (*Diagnóstico → Estrategia → Implementación → Optimización*).
   - Matriz de Desafíos vs. Soluciones reales.
5. **Conversión y Contacto:**
   - Formulario de contacto empresarial con validación en tiempo real y asistencia directa a WhatsApp.
   - Botón flotante de WhatsApp con badge y notificación.
6. **Cumplimiento Legal y Normativo:**
   - `politica-privacidad.html`: Regulada bajo la **Ley 1581 de 2012** y Decreto 1377 de 2013 de Colombia.
   - `terminos-y-condiciones.html`: Términos de uso del portal web e-global.space.
   - Etiqueta de verificación de dominio de Facebook / Meta implementada en `<head>`.
   - `robots.txt` y `sitemap.xml` para indexación SEO y Schema.org JSON-LD.

## 🛠️ Ejecución Local

Puedes visualizar el sitio de forma inmediata abriendo `index.html` en cualquier navegador web o mediante un servidor estático local:

```bash
# Con Python
python -m http.server 8080

# O con Node / npx
npx serve .
```

Luego ingresa a `http://localhost:8080`.
